# 예비중1 학부모 설명회 장표 (너희가 꽃이다, 2026-11-06)

- 보는 곳: https://nk962.github.io/neokkot-pre-ms1/
- 넘기기: → 키, 스페이스, 화면 오른쪽 클릭, 휴대폰은 옆으로 밀기 / 뒤로: ← 키, 화면 왼쪽 클릭
- 특정 장으로 가기: 주소 끝에 `#번호` (예: `#7`)

## 고치는 법
글은 모두 `index.html` 한 파일에 있습니다. 장마다 `<!-- 7 자유학기 자체 교재 -->` 같은 주석이 붙어 있으니 그 아래 글자만 바꾸고 저장(Commit)하면 1~2분 뒤 위 주소에 반영됩니다.
- 강조색 글자: `<span class="c">…</span>` / 굵은 글자: `<b>…</b>`
- 장 번호는 자동으로 붙습니다.
- 그림은 `assets/`, 글꼴은 `fonts/` 에 있습니다.
